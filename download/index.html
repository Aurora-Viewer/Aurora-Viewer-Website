Aurora Viewer for Windows

Aurora-Viewer-v0.9.9-windows-x64.zip · 80.6 MB

Download .zip
SHA-256 checksum All files of this release

Install in three steps

  1. Download the archive

    Click Download .zip above. Nothing to install as an administrator.

  2. Extract it

    Right-click the file › Extract All…, into the folder of your choice.

  3. Start the viewer

    Double-click aurora-viewer.exe.

If Windows shows “Windows protected your PC”

Click More info, then Run anyway. The releases are not code-signed yet: read our code signing policy.

Requirements

System
Windows 10 or 11, 64-bit
Graphics
A card with a Vulkan driver

Updates in one click

At launch, Aurora offers the new version, downloads it in the background, installs it and restarts your session. It tells you first whether your cache and settings are kept.

Aurora Viewer for Linux

Aurora-Viewer-v0.9.9-linux-x64.tar.gz · 83.8 MB

Download .tar.gz
SHA-256 checksum Full Linux guide

Install in three steps

  1. Install the system packages

    Vulkan, sound and windowing, plus GStreamer and the browser libraries for web pages and video.

    sudo pacman -S --needed vulkan-icd-loader alsa-lib libxkbcommon wayland libx11 libxcursor libxrandr libxi \
  gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad gst-plugins-ugly gst-libav \
  nss nspr at-spi2-core libcups libxcomposite libxdamage mesa pango cairo
    sudo apt install libvulkan1 libasound2t64 libxkbcommon0 libwayland-client0 libx11-6 libxcursor1 libxrandr2 libxi6 \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-plugins-ugly gstreamer1.0-libav \
  libnss3 libatk-bridge2.0-0t64 libcups2t64 libxcomposite1 libxdamage1 libgbm1 libpango-1.0-0 libcairo2

    Plus your card’s Vulkan driver if it is missing: vulkan-radeon, vulkan-intel, mesa-vulkan-drivers or the NVIDIA driver.

  2. Check and extract

    Put the archive and its .sha256 file in the same folder, then:

    sha256sum -c Aurora-Viewer-v0.9.9-linux-x64.tar.gz.sha256
tar -xzf Aurora-Viewer-v0.9.9-linux-x64.tar.gz

  3. Start the viewer

    cd Aurora-Viewer-v0.9.9-linux-x64
./aurora-viewer

    To add it to your desktop’s menu with its icon, follow the desktop entry steps.

Requirements

Processor
64-bit PC (x86-64)
Graphics
A Vulkan driver
System
glibc 2.39 or later: Arch, CachyOS, Fedora 40+, Ubuntu 24.04+, Debian 13
Desktop
X11 or Wayland

Updates

The viewer tells you when a new version is out. Extract the new archive as in step 2: your settings, cache and logs are kept.

Aurora Viewer for macOS

Aurora-Viewer-v0.9.9-macos-arm64.dmg · 80.6 MB

Download .dmg
SHA-256 checksum Full macOS guide

Install in three steps

  1. Open the disk image

    Double-click the .dmg in the Finder: a window shows Aurora Viewer next to your Applications folder.

  2. Drag it into Applications

    Drag Aurora Viewer onto Applications, then eject the disk image.

  3. Start the viewer

    Open Aurora Viewer from Applications or the Launchpad.

If macOS cannot check the application

Click Done, open System Settings › Privacy & Security, scroll down and click Open Anyway. macOS remembers the choice. Or, in the Terminal:

xattr -dr com.apple.quarantine "/Applications/Aurora Viewer.app"

Requirements

Mac
Apple Silicon (M1 or later). Intel Macs are not supported.
System
macOS 13 Ventura or later

Updates

The viewer tells you when a new version is out. Install the new disk image as in step 2: your settings, cache and logs are kept.
