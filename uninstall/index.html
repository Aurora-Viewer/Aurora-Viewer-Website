Uninstall Aurora Viewer

Updated: 6 November 2026

Aurora Viewer has no installer. Removing it means deleting the viewer, the data it keeps for you, and the few things it may have added to your system. Close the viewer first. Your inventory, your friends and the rest of your Second Life account stay on Linden Lab's servers: removing the viewer does not touch them.

What the viewer sends and keeps is described in the privacy policy.

The quick way

From version 0.9.3: Preferences › Language and updates › Remove Aurora from this computer, or the command aurora-viewer --uninstall, removes what Aurora registered outside its own folders: the link handler and the notification entry (step 1), the credential store entries (step 4) and the Blender add-on (step 5). It then lists the folders left to delete, each with an Open folder button (steps 2 and 3, and the Blender backup of step 5).

1. Remove the link handler and the notification entry

If you turned on Preferences › Language and updates › Open SLURL and Hypergrid links in Aurora, turn it off before you delete the viewer. The secondlife://, hop:// and x-grid-location-info:// links then go back to the program that had them before, if any. If you never turned it on, there is nothing to do.

If the viewer is already deleted, remove its entries by hand:

  • Windows: the registry keys HKEY_CURRENT_USER\Software\Classes\secondlife, HKEY_CURRENT_USER\Software\Classes\hop and HKEY_CURRENT_USER\Software\Classes\x-grid-location-info, when their shell\open\command value names aurora-viewer.exe. In a command prompt, reg query "HKCU\Software\Classes\secondlife\shell\open\command" shows it, and reg delete "HKCU\Software\Classes\secondlife" /f removes the key; do the same for hop and x-grid-location-info. Leave a key that names another program, and the keys of a viewer installed for all users, under HKEY_LOCAL_MACHINE.
  • Linux: delete ~/.local/share/applications/aurora-viewer-slurl.desktop. Then, in ~/.config/mimeapps.list, section [Default Applications], remove aurora-viewer-slurl.desktop; from the x-scheme-handler/secondlife, x-scheme-handler/hop and x-scheme-handler/x-grid-location-info lines, and delete a line left empty. If XDG_DATA_HOME or XDG_CONFIG_HOME is set, these files are in those folders instead.
  • macOS: Aurora does not open these links on macOS yet. Nothing to do.

On Windows, if you turned on the viewer's system notifications, it also wrote the name and icon Windows shows on them under HKEY_CURRENT_USER\Software\Classes\AppUserModelId\Aurora.Viewer. reg delete "HKCU\Software\Classes\AppUserModelId\Aurora.Viewer" /f removes it.

2. Delete the viewer

  • Windows: delete the folder you extracted the viewer into. An update may have left a .aurora-update-… folder or a .<folder name>.update.lock file next to it: delete them too.
  • Linux: delete the folder you extracted the viewer into. If you installed its desktop entry and icon, as the install guide shows, delete ~/.local/share/applications/aurora-viewer.desktop and ~/.local/share/icons/hicolor/scalable/apps/aurora-viewer.svg.
  • macOS: drag Aurora Viewer from Applications to the Bin. macOS may also have kept ~/Library/Preferences/org.aurora-viewer.AuroraViewer.plist and ~/Library/Saved Application State/org.aurora-viewer.AuroraViewer.savedState: delete them too.

3. Delete your data

Settings, conversation logs, caches, logs and the web and media support are kept outside the viewer's folder. Delete these folders:

SystemFolderWhat it holds
Windows%APPDATA%\Aurora\AuroraViewerSettings, accounts, conversation logs, dictionaries
Windows%LOCALAPPDATA%\Aurora\AuroraViewerCache, logs, crash reports, web and media support
Linux~/.config/auroraviewerSettings, accounts, conversation logs, dictionaries
Linux~/.cache/auroraviewerCache
Linux~/.local/share/auroraviewerLogs, crash reports, web and media support
macOS~/Library/Application Support/org.Aurora.AuroraViewerSettings, accounts, conversation logs, dictionaries, logs, crash reports, web and media support
macOS~/Library/Caches/org.Aurora.AuroraViewerCache

On Windows, paste the folder's name into the address bar of File Explorer; the Aurora folders above them can go too once empty. On a Mac, use Go › Go to Folder… (Cmd+Shift+G) in the Finder. On Linux, XDG_CONFIG_HOME, XDG_CACHE_HOME or XDG_DATA_HOME, when set, replace ~/.config, ~/.cache and ~/.local/share.

Also check these, if they apply to you:

  • A cache folder you chose in Preferences › Network and cache › Location: delete the AuroraViewerCache folder inside it. The viewer writes nothing else there.
  • A conversation logs folder you chose in Preferences › Chat › History: delete the account folders inside it.
  • Your photos: by default in an Aurora Viewer folder of your Pictures folder. Keep them, or delete them.

4. Remove the saved passwords and keys

The viewer keeps a few items in your system's credential store. Their names start with "Aurora Viewer":

  • Aurora Viewer: remembered logins, one per account and grid (the hashed password only).
  • Aurora Viewer MFA: remembered two-factor logins.
  • Aurora Viewer GitHub: the GitHub authorisation for crash reports.
  • Aurora Viewer cache: a key the disk cache uses.

To remove them:

  • Windows: Control Panel › Credential Manager › Windows Credentials. Under Generic Credentials, remove the entries whose names end in "Aurora Viewer", "Aurora Viewer MFA", "Aurora Viewer GitHub" or "Aurora Viewer cache".
  • Linux: your desktop's password manager, which holds the Secret Service entries (Passwords and Keys on GNOME, KWallet on KDE). Search for "Aurora Viewer". Without a credential store, the cache key is a cache.key file in the settings folder, deleted with it in step 3.
  • macOS: Keychain Access, login keychain. Search for "Aurora Viewer" and delete the entries.

If you authorised the viewer on GitHub for crash or bug reports, you can also revoke it on github.com: Settings › Applications › Authorized GitHub Apps.

5. Remove the Blender add-on

If you installed the LiveMesh add-on from the viewer, remove it in Blender: Edit › Preferences › Add-ons, find Aurora LiveMesh, and choose Uninstall in its menu. Its files are in Blender's folder for that version (for example %APPDATA%\Blender Foundation\Blender\4.2 on Windows, ~/.config/blender/4.2 on Linux, ~/Library/Application Support/Blender/4.2 on macOS): extensions/user_default/aurora_live_mesh from Blender 4.2, scripts/addons/aurora_live before.

Before installing it, the viewer saved your Blender settings from before the add-on in an aurora-backups folder, next to an .aurora-install.lock file, in that same Blender folder. Keep that copy, or delete them.

Désinstaller Aurora Viewer

Mis à jour le 6 novembre 2026

Aurora Viewer n'a pas d'installateur. Le retirer, c'est supprimer le viewer, les données qu'il garde pour vous et les quelques éléments qu'il a pu ajouter à votre système. Fermez d'abord le viewer. Votre inventaire, vos amis et le reste de votre compte Second Life restent sur les serveurs de Linden Lab : retirer le viewer n'y touche pas.

Ce que le viewer envoie et garde est décrit dans la politique de confidentialité.

La méthode rapide

À partir de la version 0.9.3 : Préférences › Langue et mises à jour › Retirer Aurora de cet ordinateur, ou la commande aurora-viewer --uninstall, retire ce qu'Aurora a enregistré hors de ses propres dossiers : le gestionnaire de liens et l'entrée des notifications (étape 1), les entrées du coffre d'identifiants (étape 4) et l'extension Blender (étape 5). Puis elle liste les dossiers qui restent à supprimer, chacun avec un bouton Ouvrir le dossier (étapes 2 et 3, et la sauvegarde Blender de l'étape 5).

1. Retirer le gestionnaire de liens et l'entrée des notifications

Si vous avez activé Préférences › Langue et mises à jour › Ouvrir les liens SLURL et Hypergrid dans Aurora, désactivez-le avant de supprimer le viewer. Les liens secondlife://, hop:// et x-grid-location-info:// reviennent alors au programme qui les ouvrait avant, s'il y en avait un. Si vous ne l'avez jamais activé, il n'y a rien à faire.

Si le viewer est déjà supprimé, retirez ses entrées à la main :

  • Windows : les clés de registre HKEY_CURRENT_USER\Software\Classes\secondlife, HKEY_CURRENT_USER\Software\Classes\hop et HKEY_CURRENT_USER\Software\Classes\x-grid-location-info, quand leur valeur shell\open\command nomme aurora-viewer.exe. Dans une invite de commandes, reg query "HKCU\Software\Classes\secondlife\shell\open\command" l'affiche, et reg delete "HKCU\Software\Classes\secondlife" /f supprime la clé ; faites de même pour hop et x-grid-location-info. Laissez une clé qui nomme un autre programme, ainsi que les clés d'un viewer installé pour tous les utilisateurs, sous HKEY_LOCAL_MACHINE.
  • Linux : supprimez ~/.local/share/applications/aurora-viewer-slurl.desktop. Puis, dans ~/.config/mimeapps.list, section [Default Applications], retirez aurora-viewer-slurl.desktop; des lignes x-scheme-handler/secondlife, x-scheme-handler/hop et x-scheme-handler/x-grid-location-info, et supprimez une ligne restée vide. Si XDG_DATA_HOME ou XDG_CONFIG_HOME est défini, ces fichiers sont dans ces dossiers-là.
  • macOS : Aurora n'ouvre pas encore ces liens sur macOS. Rien à faire.

Sous Windows, si vous avez activé les notifications système du viewer, il a aussi écrit le nom et l'icône que Windows y affiche sous HKEY_CURRENT_USER\Software\Classes\AppUserModelId\Aurora.Viewer. reg delete "HKCU\Software\Classes\AppUserModelId\Aurora.Viewer" /f la supprime.

2. Supprimer le viewer

  • Windows : supprimez le dossier où vous avez extrait le viewer. Une mise à jour a pu laisser à côté un dossier .aurora-update-… ou un fichier .<nom du dossier>.update.lock : supprimez-les aussi.
  • Linux : supprimez le dossier où vous avez extrait le viewer. Si vous avez installé son entrée de bureau et son icône, comme le montre le guide d'installation, supprimez ~/.local/share/applications/aurora-viewer.desktop et ~/.local/share/icons/hicolor/scalable/apps/aurora-viewer.svg.
  • macOS : faites glisser Aurora Viewer des Applications vers la Corbeille. macOS a pu garder aussi ~/Library/Preferences/org.aurora-viewer.AuroraViewer.plist et ~/Library/Saved Application State/org.aurora-viewer.AuroraViewer.savedState : supprimez-les aussi.

3. Supprimer vos données

Les réglages, les historiques de conversation, les caches, les journaux et la prise en charge du web et des médias sont gardés hors du dossier du viewer. Supprimez ces dossiers :

SystèmeDossierCe qu'il contient
Windows%APPDATA%\Aurora\AuroraViewerRéglages, comptes, historiques de conversation, dictionnaires
Windows%LOCALAPPDATA%\Aurora\AuroraViewerCache, journaux, rapports de plantage, prise en charge du web et des médias
Linux~/.config/auroraviewerRéglages, comptes, historiques de conversation, dictionnaires
Linux~/.cache/auroraviewerCache
Linux~/.local/share/auroraviewerJournaux, rapports de plantage, prise en charge du web et des médias
macOS~/Library/Application Support/org.Aurora.AuroraViewerRéglages, comptes, historiques de conversation, dictionnaires, journaux, rapports de plantage, prise en charge du web et des médias
macOS~/Library/Caches/org.Aurora.AuroraViewerCache

Sous Windows, collez le nom du dossier dans la barre d'adresse de l'Explorateur de fichiers ; les dossiers Aurora au-dessus peuvent partir aussi une fois vides. Sur un Mac, utilisez Aller › Aller au dossier… (Cmd+Maj+G) dans le Finder. Sous Linux, XDG_CONFIG_HOME, XDG_CACHE_HOME ou XDG_DATA_HOME, s'ils sont définis, remplacent ~/.config, ~/.cache et ~/.local/share.

Vérifiez aussi ceux-ci, s'ils vous concernent :

  • Un dossier de cache que vous avez choisi dans Préférences › Réseau et cache › Emplacement : supprimez le dossier AuroraViewerCache qu'il contient. Le viewer n'y écrit rien d'autre.
  • Un dossier des historiques de conversation que vous avez choisi dans Préférences › Chat › Historique : supprimez les dossiers de comptes qu'il contient.
  • Vos photos : par défaut dans un dossier Aurora Viewer de votre dossier Images. Gardez-les, ou supprimez-les.

4. Retirer les mots de passe et clés enregistrés

Le viewer garde quelques éléments dans le coffre d'identifiants de votre système. Leur nom commence par « Aurora Viewer » :

  • Aurora Viewer : les connexions enregistrées, une par compte et par grille (seulement l'empreinte du mot de passe).
  • Aurora Viewer MFA : les connexions à double authentification retenues.
  • Aurora Viewer GitHub : l'autorisation GitHub des rapports de plantage.
  • Aurora Viewer cache : une clé dont se sert le cache disque.

Pour les retirer :

  • Windows : Panneau de configuration › Gestionnaire d'identification › Informations d'identification Windows. Sous Informations d'identification génériques, supprimez les entrées dont le nom se termine par « Aurora Viewer », « Aurora Viewer MFA », « Aurora Viewer GitHub » ou « Aurora Viewer cache ».
  • Linux : le gestionnaire de mots de passe de votre bureau, qui tient les entrées du Secret Service (Mots de passe et clés sous GNOME, KWallet sous KDE). Cherchez « Aurora Viewer ». Sans coffre d'identifiants, la clé du cache est un fichier cache.key du dossier des réglages, supprimé avec lui à l'étape 3.
  • macOS : Trousseaux d'accès, trousseau de session. Cherchez « Aurora Viewer » et supprimez les entrées.

Si vous avez autorisé le viewer sur GitHub pour les rapports de plantage ou de bug, vous pouvez aussi révoquer cette autorisation sur github.com : Settings › Applications › Authorized GitHub Apps.

5. Retirer l'extension Blender

Si vous avez installé l'extension LiveMesh depuis le viewer, retirez-la dans Blender : Édition › Préférences › Add-ons, trouvez Aurora LiveMesh, puis choisissez Désinstaller dans son menu. Ses fichiers sont dans le dossier de Blender pour cette version (par exemple %APPDATA%\Blender Foundation\Blender\4.2 sous Windows, ~/.config/blender/4.2 sous Linux, ~/Library/Application Support/Blender/4.2 sur macOS) : extensions/user_default/aurora_live_mesh à partir de Blender 4.2, scripts/addons/aurora_live avant.

Avant de l'installer, le viewer a gardé vos réglages Blender d'avant l'extension dans un dossier aurora-backups, à côté d'un fichier .aurora-install.lock, dans ce même dossier de Blender. Gardez cette copie, ou supprimez-les.
