Code signing policy

Effective date: from the first signed release

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signing lets Windows and security software check that the program you downloaded is the one the Aurora team released, unchanged.

What is signed

  • The Windows program aurora-viewer.exe of each release published on the project's GitHub releases page.
  • Only builds of the public source code. The program is built by the project's Release workflow on GitHub Actions, from the version tag of the public repository Aurora-Viewer/Aurora-Viewer, and that workflow sends it to SignPath. A build made on a developer's computer is never signed.
  • Every release is approved by hand by one of the approvers below before it is signed.
  • The media plugins the viewer downloads when you open web pages or videos on media faces are other projects' code, built from their sources: they are not signed with this certificate.

Team roles

  • Committers and reviewers: the members of the Aurora-Viewer GitHub organization with write access to the repository
  • Approvers: Odessa-Draekavik

Changes from people outside the team are reviewed in a pull request before they are merged. Every team member uses multi-factor authentication on GitHub and on SignPath.

Privacy

The Aurora team runs no server. The viewer connects to Second Life (or the grid you choose) when you log in, and contacts other services only for the features described in the privacy policy: what it sends, to whom, and what it keeps on your computer.

Check a download

  • In Windows, right-click aurora-viewer.exe, then Properties › Digital Signatures: the signer is SignPath Foundation.
  • Each release also gives the SHA-256 of its zip file (the .sha256 file next to it).

Contact

To report a signed file that should not be, or a problem with a signature: contact@aurora-viewer.org.

Politique de signature du code (code signing policy)

Date d'effet : à partir de la première version signée

Free code signing provided by SignPath.io, certificate by SignPath Foundation : la signature est offerte par SignPath.io, avec le certificat de la SignPath Foundation.

La signature permet à Windows et aux logiciels de sécurité de vérifier que le programme téléchargé est bien celui publié par l'équipe d'Aurora, sans modification.

Ce qui est signé

  • Le programme Windows aurora-viewer.exe de chaque version publiée sur la page des versions GitHub du projet.
  • Uniquement les compilations du code source public. Le programme est compilé par le workflow Release du projet sur GitHub Actions, à partir de l'étiquette de version du dépôt public Aurora-Viewer/Aurora-Viewer, et c'est ce workflow qui l'envoie à SignPath. Une compilation faite sur l'ordinateur d'un développeur n'est jamais signée.
  • Chaque version est approuvée à la main par l'une des personnes chargées de l'approbation ci-dessous avant d'être signée.
  • Les plugins média que le viewer télécharge quand vous ouvrez des pages web ou des vidéos sur des faces média sont le code d'autres projets, compilé à partir de leurs sources : ils ne sont pas signés avec ce certificat.

Rôles de l'équipe

  • Auteurs et relecteurs : les membres de l'organisation GitHub Aurora-Viewer ayant les droits d'écriture sur le dépôt
  • Approbation : Odessa-Draekavik

Les modifications proposées par des personnes extérieures à l'équipe sont relues dans une pull request avant d'être fusionnées. Chaque membre de l'équipe utilise l'authentification à plusieurs facteurs sur GitHub et sur SignPath.

Confidentialité

L'équipe d'Aurora n'exploite aucun serveur. Le viewer se connecte à Second Life (ou à la grille de votre choix) quand vous vous connectez, et ne contacte d'autres services que pour les fonctions décrites dans la politique de confidentialité : ce qu'il envoie, à qui, et ce qu'il garde sur votre ordinateur.

Vérifier un téléchargement

  • Dans Windows, clic droit sur aurora-viewer.exe, puis Propriétés › Signatures numériques : le signataire est SignPath Foundation.
  • Chaque version donne aussi l'empreinte SHA-256 de son fichier zip (le fichier .sha256 à côté).

Contact

Pour signaler un fichier signé qui ne devrait pas l'être, ou un problème de signature : contact@aurora-viewer.org.
